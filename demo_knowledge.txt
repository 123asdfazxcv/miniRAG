===========================================
LightSpeed Tech 公司内部知识库
===========================================

## 公司概况
LightSpeed Tech 成立于 2019 年，总部位于深圳南山科技园，在北京和上海设有分公司。
公司主营业务是企业级 AI 中间件，核心产品包括数据管道平台 DataFlow、智能客服系统 SmartDesk、
以及实时数据分析引擎 RTEngine。2023 年完成 B 轮融资 2.3 亿元人民币，投资方包括红杉资本和高瓴资本。
目前公司员工约 350 人，其中研发团队占 60% 以上。

## 产品：DataFlow 数据管道平台
DataFlow 是一个低代码数据集成平台，支持从 MySQL、PostgreSQL、MongoDB、Kafka 等 20+ 种数据源
实时同步数据到数据仓库或数据湖。核心特性包括：
- 可视化拖拽配置管道，无需编写 ETL 代码
- 支持全量同步和增量 CDC（Change Data Capture）同步
- 内置数据清洗、格式转换、脱敏等 50+ 种算子
- 单管道吞吐量可达 10 万条/秒
- 支持断点续传，网络中断后可从断点继续同步
DataFlow 按数据量计费，基础版每 GB 0.5 元，企业版每 GB 0.3 元。
目前已有 600+ 企业客户在使用 DataFlow，包括招商银行、比亚迪、美的集团等。

## 产品：SmartDesk 智能客服系统
SmartDesk 是基于大语言模型的智能客服系统，支持 Web、微信、钉钉、飞书等多渠道接入。
核心能力：
- 基于 RAG（检索增强生成）技术，支持客户上传 PDF、Word、网页等知识库文档
- 多轮对话理解，能记住上下文，支持打断和意图切换
- 支持人工客服无缝接管，AI 回答置信度低时自动转人工
- 支持中英文和粤语混合对话
- 每个客服机器人支持最多 10 万条知识库文档
SmartDesk 按坐席收费，标准版每坐席每月 299 元，旗舰版每坐席每月 599 元（含高级分析和报表）。
目前已有 1200+ 客户在使用 SmartDesk，日均处理对话量超过 500 万条。

## 产品：RTEngine 实时数据分析引擎
RTEngine 是一个面向实时数据流的分析引擎，支持 SQL 查询实时流数据。
核心特性：
- 兼容 Flink SQL 语法，降低学习成本
- 支持滑动窗口、会话窗口、累积窗口等多种窗口计算
- 端到端延迟低于 100 毫秒
- 内置 30+ 种聚合函数和异常检测算法
- 支持对接 Grafana、DataV 等可视化平台
RTEngine 按计算单元 CU 计费，每 CU 每小时 1.2 元。
目前已有 300+ 客户在使用 RTEngine，主要用在实时风控、IoT 监控、实时大屏等场景。

## 入职流程
新员工入职需要完成以下步骤：
1. 收到 Offer 后，HR 会发送入职指引邮件，包含入职日期和需要携带的材料清单
2. 入职当天上午 9:30 到公司前台签到，领取工牌和入职礼包
3. 上午 10:00-11:30 参加新员工入职培训，了解公司文化、组织架构和规章制度
4. 下午 14:00 由直属 Leader 带领认识团队成员，分配工作设备和账号
5. 第一天结束前需要在 OA 系统完成个人信息录入
6. 入职第一周需要完成在线合规培训课程（信息安全、反腐败、数据隐私）
7. 试用期 3 个月，每个月有一次转正评估面谈
8. 试用期结束后提交转正申请，通过评审后转为正式员工

## 报销政策
员工因公产生的费用可按以下流程报销：
1. 在 OA 系统中提交报销申请，上传发票照片
2. 差旅费包含机票、火车票、酒店住宿、市内交通（出租车或网约车）
3. 招待费：每人次不超过 300 元，需提前在 OA 提交招待申请
4. 办公用品：每月额度 200 元/人
5. 培训费：与工作相关的培训课程费用，需 Leader 审批
6. 报销单金额 5000 元以下由部门 Leader 审批，5000 元以上需总监加签
7. 报销款项在审批通过后 5 个工作日内打入工资卡

## 技术栈与研发规范
公司技术栈以 Java 和 Python 为主：
- 后端服务使用 Spring Boot + MyBatis，微服务架构基于 Kubernetes 部署
- 数据处理管道使用 Flink + Kafka
- AI 相关服务使用 Python + PyTorch，模型推理服务部署在 Triton Inference Server
- 前端使用 React + TypeScript，UI 组件库基于 Ant Design 定制
- 代码管理使用 GitLab，CI/CD 使用 Jenkins + ArgoCD
- 代码审查（Code Review）是强制性的，每个 MR 至少需要一名 Reviewer Approve
- 单元测试覆盖率要求 80% 以上，核心模块要求 90%
- 每次上线需要有上线检查清单（Checklist）和回滚方案

## 常见问题 FAQ

Q: 公司支持远程办公吗？
A: 公司支持混合办公模式，每周可以申请 2 天远程办公，需要提前在 OA 系统申请并经 Leader 审批。
核心工作日（周一和周三）建议在办公室，便于团队沟通。

Q: 加班有加班费吗？
A: 公司不鼓励加班。如确因项目需要加班，可申请调休，加班时长按 1:1 兑换调休假。
调休需在加班发生后 30 天内使用，过期清零。

Q: 可以申请内部转岗吗？
A: 入职满 1 年的员工可以申请内部转岗。流程：在 OA 提交转岗申请 → HR 评估 → 目标部门面试 →
双方 Leader 沟通 → 转岗生效。转岗后试用期 1 个月。

Q: 公司有年终奖吗？
A: 公司一般在每年 1 月份发放年终奖，金额根据个人绩效和公司业绩综合评定。
通常为 1-3 个月工资。入职不满 1 年的按实际上班天数折算。

Q: DataFlow 支持私有化部署吗？
A: 支持。DataFlow 企业版支持私有化部署到客户的 Kubernetes 集群或物理服务器上。
私有化部署需要一次性购买 License，价格为 50 万元/年起，包含第一年维保。

Q: SmartDesk 支持对接企业微信吗？
A: 支持。SmartDesk 支持对接企业微信、钉钉、飞书等主流办公平台。
对接流程：在管理后台添加渠道 → 配置 Webhook 地址 → 扫码授权 → 完成部署。
整个过程大约需要 5 分钟。此外，SmartDesk 还支持通过 API 对接自研系统。
